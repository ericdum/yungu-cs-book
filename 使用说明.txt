═══════════════════════════════════════════════════════════════
  OpenBook 静态网站使用说明
═══════════════════════════════════════════════════════════════

⚠️  重要提示：不能直接双击打开 index.html 文件！

由于浏览器的安全策略（CORS），直接打开 HTML 文件会导致无法加载
navigation.json 和其他 Markdown 文件。

═══════════════════════════════════════════════════════════════
  正确的使用方法
═══════════════════════════════════════════════════════════════

方法一：使用启动脚本（最简单）

  macOS/Linux:
    1. 打开终端
    2. 进入 openbook 目录
    3. 运行: ./start.sh
    4. 在浏览器中访问: http://localhost:8000

  Windows:
    1. 双击 start.bat 文件
    2. 在浏览器中访问: http://localhost:8000

方法二：手动启动服务器

  1. 打开终端/命令提示符
  2. 进入 openbook 目录
  3. 首次运行需要安装依赖:
     npm install
  4. 启动开发服务器:
     npm run dev
  5. 浏览器会自动打开，或手动访问: http://localhost:8000

  注意: 需要先安装 Node.js (https://nodejs.org/)

═══════════════════════════════════════════════════════════════
  更新内容
═══════════════════════════════════════════════════════════════

当更新了 chapters/ 目录中的 .tex 文件后：

  1. 运行转换脚本:
     python3 tools/tex_to_markdown.py elegantbook-cn.tex openbook/

  2. 刷新浏览器页面即可看到更新
