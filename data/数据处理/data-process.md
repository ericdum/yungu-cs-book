# 数据处理与分析

了解了表格的基本结构后，让我们学习如何处理和分析数据。在表格软件中，正确地表示、观察和分析数据是核心技能。

## 让数据正确地显示

在表格软件中，数据的正确表示至关重要。不同类型的数据有不同的显示格式和处理方式，了解这些格式的特点和切换方法，能避免很多数据处理错误。

### 数字格式

数字是最常见的数据类型，有多种显示格式：

| **格式**  | **示例**  | **适用场景**  |
| --- | --- | --- |
| 标准数字 | 123.45 | 普通数值计算 |
| 千分位 | 1,234.56 | 大数字的可读性显示 |
| 货币 | ¥1,234.56 | 价格、金额显示 |
| 百分比 | 85% | 比例、占比显示 |
| 科学计数法 | 1.23E+03 | 很大或很小的数字 |


**注意事项**：

- 数字格式影响计算结果：百分比格式下输入80会显示为80%，但实际值为0.8
- 千分位只是显示格式，不影响计算
- 货币符号会根据地区设置自动调整

**常见错误**：

- 输入"85%"，系统当作文本处理，无法参与计算
- 大数字不加千分位，难以阅读和理解
- 价格数据用普通数字格式，缺少货币标识

### 日期和时间

时间数据的正确格式至关重要：

| **格式**  | **示例**  | **适用场景**  |
| --- | --- | --- |
| 日期 | 2024/12/10 或 2024-12-10 | 记录日期 |
| 时间 | 14:30:25 | 记录具体时间点 |
| 日期时间 | 2024/12/10 14:30 | 记录完整的时间点 |

**注意事项**：

- 日期格式要统一，否则无法正确排序
- 系统内部存储为数字序列号，便于计算时间差
- 不同地区有不同的日期格式习惯

**常见错误**：

- 用文本格式存储日期，无法按时间排序
- 日期格式不统一（如混用2024/12/10和12/10/2024）
- 把日期当作普通文本，错过时间计算功能

### 文本格式

文本用于描述和标识，不参与数值计算。

**特征**：

- 以等号开头的公式会被当作文本
- 数字也可以是文本（如学号、电话号码）
- 支持查找、替换、合并等文本操作

**常见错误**：

- 把数值当作文本存储，求和时被忽略
- 日期用文本格式，无法计算天数差
- 身份证号用数值格式，失去前导零

> **格式切换技巧**
>
>
> - **快捷键**：Ctrl+1（Windows）或Cmd+1（Mac）打开格式设置对话框
> - **批量操作**：选中多个单元格后设置格式，保持数据格式一致性
> - **预览效果**：格式设置后立即查看显示效果，确保符合预期
> - **撤销操作**：Ctrl+Z/Cmd+Z可以撤销格式设置
>
>

## 观察数据

数据收集只是第一步，接下来我们需要通过合理的方式去观察数据。

### 排序

**目的**：按某个属性的顺序排列，找出最大值、最小值、中位数。

**示例**：按总分降序排列，找出成绩最好的学生。

**适用场景**：

- 找出最高/最低分
- 按时间排序
- 按字母顺序排列

### 筛选

**目的**：只显示符合条件的数据，聚焦关注的信息。

**示例**：筛选出数学成绩>80的学生。

**适用场景**：

- 找出特定条件的数据
- 排除异常值
- 聚焦分析对象

### 分组

**目的**：按类别汇总数据，发现类别间的差异。

**示例**：按爱好分组，统计每个爱好的人数。

**适用场景**：

- 按类别统计
- 比较不同组别
- 发现分布规律

> **核心思维**
>
> **数据操作的本质是提问**：我想知道什么？我需要什么信息？
>
> 操作只是回答这些问题的方法。
>

## 数据分析：公式的力量

填入单元格的不只可以是具体的数据，也可以是一个公式。公式让表格能够自动计算，是数据分析的核心工具。

### 公式的基本结构

公式以等号（=）开头，后面跟着算式。算式可以是简单的数学运算，也可以是函数调用。

**格式**：=算式

**组成**：

- **简单数学算式**：直接用+-*/表达，如 =5+2 或 =B1+B2
- **函数**：复杂的计算需要使用函数，如 =AVG(B2) 或 =SUM(A1:A10)

### 数据引用方式

公式可以引用单元格中的数据，有多种引用方式：

| **引用类型**  | **示例**  | **说明**  |
| --- | --- | --- |
| 单独单元格 | =A1 | 引用单个单元格，如A1、B2等 |
| 整行 | =SUM(1:1) | 引用整行，用行号表示 |
| 整列 | =SUM(A:A) | 引用整列，用列号表示 |
| 单元格范围 | =SUM(A1:A10) | 引用连续的单元格区域 |
| 多行 | =SUM(1:5) | 引用第1到第5行 |
| 多列 | =SUM(A:C) | 引用从A列到C列 |

### 常用函数

| **函数**  | **用途**  | **思维方式**  | **示例**  |
| --- | --- | --- | --- |
| SUM | 求和 | 把这些单元格加起来 | =SUM(B2:B10) |
| AVERAGE | 平均 | 计算这些单元格的平均值 | =AVERAGE(B2:B10) |
| COUNT | 计数 | 统计这些单元格中数字个数 | =COUNT(B2:B10) |
| MAX | 最大值 | 找出这些单元格中的最大值 | =MAX(B2:B10) |
| MIN | 最小值 | 找出这些单元格中的最小值 | =MIN(B2:B10) |
| IF | 条件判断 | 如果...则...否则... | =IF(B2>80,"优秀","良好") |

### 公式示例

**场景1：计算总分**

假设A列是姓名，B、C、D列分别是数学、英语、语文成绩，E列要计算总分：

```

=B2+C2+D2

```

或者使用SUM函数：

```

=SUM(B2:D2)

```

**场景2：计算平均分**

计算所有学生的数学平均分：

```

=AVERAGE(B2:B10)

```

**场景3：条件判断**

如果成绩大于80显示"优秀"，否则显示"良好"：

```

=IF(B2>80,"优秀","良好")

```

> **公式学习建议**
>
>
> 1. **先想清楚要算什么**：确定目标后再选择合适的函数
> 2. **从简单开始**：先掌握SUM、AVERAGE、MAX、MIN等基础函数
> 3. **善用帮助**：不确定语法时查阅软件的帮助文档
> 4. **多练习**：公式是熟能生巧的技能
>
>

## 常见错误及解决方案

| **错误**  | **后果**  | **解决方案**  |
| --- | --- | --- |
| 数值用文本格式存储 | 无法参与求和、排序结果错误 | 转换为数字格式 |
| 日期用文本格式存储 | 无法按时间排序、计算时间间隔 | 转换为日期格式 |
| 百分比直接输入% | 被当作文本，无法正确计算 | 先输入数字，再设置格式 |
| 身份证号用数字格式 | 失去前导零，变成错误编号 | 转换为文本格式 |
